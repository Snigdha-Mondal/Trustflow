# docs/ — Project Paper Trail

This directory maintains the permanent record of architectural decisions, feature stories, implementation plans, and manual test scripts.

## Subdirectories
- **`adr/`**: Architecture Decision Records. Documents why significant architectural choices were made.
- **`stories/`**: User stories and feature specifications for major components.
- **`plans/`**: Step-by-step build plans linking to backlog items.
- **`manual-tests/`**: Test scripts for human testers documenting what automated tests cannot prove.
